# كارفور دشنا — موقع ونظام طلبات المطعم

موقع كامل (واجهة العميل + لوحة الإدارة + خادم + قاعدة بيانات دائمة) بدون أي مكتبات خارجية، فلا يوجد `npm install`.

## التشغيل على جهازك (VS Code)
1. ثبّت **Node.js 22.5 أو أحدث** (من nodejs.org).
2. افتح مجلد المشروع في VS Code ثم الـ Terminal:
   ```
   npm start
   ```
3. افتح: الموقع `http://localhost:3000` — الإدارة `http://localhost:3000/admin` (أو زر «الإدارة» أسفل الصفحة).

## الدخول الأولي
- اسم المستخدم: `admin` — كلمة المرور: `mohamed amer 123`
- تُنشأ مرة واحدة فقط عند أول تشغيل، وتُخزَّن مشفّرة (scrypt) في الخادم، وليست في كود الواجهة.
- **غيّرها فورًا** من لوحة الإدارة ← «الحساب». يمكن أيضًا ضبط `ADMIN_USER` و`ADMIN_PASSWORD` في `.env` قبل أول تشغيل.

## كيف يرفع المدير المنيو؟
لوحة الإدارة ← **التصنيفات** (أضف تصنيف) ← **المنتجات**: «إضافة منتج» (اسم، وصف، سعر، صورة من الجهاز) أو «رفع منيو دفعة واحدة» (سطر لكل منتج: `الاسم | السعر | الوصف`). ثم **العروض** و**الإعدادات** (رسوم التوصيل، ساعات العمل، الهاتف، العنوان، إيقاف الطلبات).
المنيو يبدأ فارغًا عمدًا — لا توجد أسعار مخترعة.

## ما الذي يعمل
- العميل: تصفح المنيو، سلة، تعديل الكميات، بيانات التوصيل، تأكيد الطلب ورقم طلب (CF-1001…)، وتتبّع لحظي للحالة.
- الإدارة: وصول الطلب فورًا (SSE) مع صوت وإشعار، تغيير الحالة (جديد ← قيد التحضير ← جاهز ← خرج للتوصيل ← مكتمل / ملغي) فتتحدث عند العميل لحظيًا، طباعة فاتورة، إحصائيات المبيعات، التحكم الكامل في المنتجات والتصنيفات والعروض والإعدادات.
- الأسعار تُحسب دائمًا من قاعدة البيانات في الخادم، وسعر العميل يُتجاهل. الطلبات القديمة تحتفظ بأسعارها وقت الطلب.
- الأمان: جلسات HttpOnly + SameSite=Strict، تحديد محاولات الدخول، فحص Origin، فحص حقيقي لملفات الصور، رؤوس أمان (CSP…).

## الاختبار
`npm test` يشغّل الخادم على قاعدة مؤقتة ويختبر المسار كاملًا (دخول، إضافة منتجات، طلب، ظهوره للمدير، تحديث الحالة عند العميل، الحماية).

## النشر على الإنترنت
المتطلب الأساسي: استضافة تشغّل Node 22.5+ **مع قرص دائم** لمجلد `data` (فيه قاعدة البيانات والصور). على الاستضافات ذات القرص المؤقت ستضيع الطلبات عند إعادة التشغيل.
- **VPS** (مثل Hetzner/DigitalOcean): `NODE_ENV=production npm start` تحت `pm2` أو `systemd`، خلف Nginx/Caddy مع HTTPS (Let's Encrypt).
- **Docker**: `docker build -t carrefour . && docker run -d -p 3000:3000 -v carrefour-data:/app/data -e ADMIN_PASSWORD="..." carrefour`
- **Render**: ملف `render.yaml` جاهز (يحتاج خطة بقرص دائم).
- **النسخ الاحتياطي**: انسخ مجلد `data` (أوقف الخادم لحظة النسخ أو استخدم `sqlite3 carrefour.db ".backup copy.db"`).
- اضبط `NODE_ENV=production` ليعمل الكوكي بوضع Secure خلف HTTPS.

## ملاحظة تقنية
اعتمدتُ SQLite (مدمجة في Node) بدل PostgreSQL+Prisma لأنها قاعدة دائمة حقيقية، وتكفي مطعمًا واحدًا بسهولة، ولا تحتاج خدمات إضافية. طبقة الوصول للبيانات في `db.js` و`server.js` إن أردت الانتقال لاحقًا إلى PostgreSQL.
